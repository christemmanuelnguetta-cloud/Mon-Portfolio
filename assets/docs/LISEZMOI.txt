cv.pdf est le CV que les visiteurs telechargent depuis le site.

Il est genere a partir de cv.html. Si tu modifies cv.html ou cv.css,
refais le PDF pour qu'il reste a jour :
  1. Ouvre cv.html dans Chrome ou Edge.
  2. Fais Ctrl + P.
  3. Destination : « Enregistrer au format PDF », marges : Aucune,
     coche « Graphiques d'arriere-plan ».
  4. Enregistre le fichier ici sous le nom cv.pdf (remplace l'ancien).
